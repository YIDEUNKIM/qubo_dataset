# R/P 고정 α 비교 실험 결과

## 실험 목적

기존 α 실험들은 α마다 `create_qubo_hardened_posiform()`을 호출하여 R과 P를 매번 재생성했다. 동일 seed로 인해 결과적으로 같은 R, P가 생성되지만, 이는 seed 결정론에 의존하는 암묵적 보장이다.

본 실험에서는 R(Σ R_i)과 P를 **인스턴스당 한 번만 생성**하고, α만 바꿔서 `Q = Σ R_i + α × P`를 결합한다. 동일한 energy landscape 위에서 α의 **순수한 영향**만 관찰한다.

## 실험 설정

| 항목 | 값 |
|---|---|
| N | 500 |
| max_subgraph_size | 15 |
| coeff_type | lin2 ({-1, +1}), lin20 ({-1.0, -0.9, ..., 0.9, 1.0}) |
| α | 0, 0.001, 0.01, 0.1 |
| SA sweeps | 100, 500, 1000, 5000 |
| SA num_reads | 50 |
| 인스턴스 수 | 100 |
| posiform_coeff_range | (1.0, 1.0) |
| 인스턴스 seed | run × 53 (run = 0, 1, ..., 99) |

### 기존 실험과의 차이

| 항목 | 기존 실험 | 본 실험 |
|---|---|---|
| R, P 생성 | α마다 재생성 (seed로 동일성 보장) | 인스턴스당 1회 생성, 명시적 공유 |
| 인스턴스 수 | 10 | **100** |
| 비교 방식 | seed 결정론에 의존 | 동일 객체 참조로 보장 |
| 계산 효율 | α × instances회 생성 (40회) | instances회 생성 (100회, but α마다 재생성 안 함) |

### 코드 구조

```python
# 인스턴스당 R, P를 1회만 생성
R_sum, Q_posiform, target = generate_components(n, coeff_type=ct, seed=run * 53)

# α만 바꿔서 결합
Q = combine(R_sum, Q_posiform, alpha)  # Q = Σ R_i + α × P
```

### 에너지 분석 핵심 관찰

**1. α=0에서만 "GS 에너지 도달 ≠ Target 일치" (축퇴)**

α=0일 때 SA는 GS 에너지를 잘 찾지만(lin2: 92.6%, lin20: 18.4%), target 비트스트링은 거의 못 찾는다(lin2: 0%, lin20: 1.5%). 이 차이(lin2: 4632개, lin20: 848개)는 전부 **축퇴된 다른 GS**에 도달한 것.

**2. α≥0.001에서 GS=Target 완벽 대응 (GS≠Target = 0)**

α=0.001만 추가해도 "GS를 찾았는데 target이 아닌 경우"가 **정확히 0**이다. 이는 극히 작은 posiform signal만으로도 축퇴가 완전히 깨져서, GS가 유일한 target이 됨을 의미한다.

**3. α=0에서 GS 에너지 도달률의 비단조적 변화**

| α | lin2 GS 에너지% (sw=1000) | 해석 |
|---|---|---|
| 0 | **82.4%** | landscape 평탄 → GS 에너지에 쉽게 도달 (but 축퇴) |
| 0.001 | **10.4%** | posiform이 plateau를 깨서 유일한 골짜기 → 찾기 어려움 |
| 0.01 | 24.0% | signal 강화 → gradient 생성으로 회복 |
| 0.1 | 99.6% | 강한 signal → 쉽게 도달 |

α=0(82.4%) → α=0.001(10.4%)에서 GS 도달률이 급락하는 것은 posiform의 **이중 효과**를 보여준다:
- 축퇴 제거: 유일한 GS를 만듦
- Landscape 변형: 동시에 에너지 장벽을 생성하여 SA가 유일한 골짜기를 찾기 어렵게 만듦

α를 키우면 gradient signal이 강해져서 다시 회복된다 (10.4% → 24.0% → 99.6%).

## 해석

### 1. α의 순수한 효과 확인

동일한 R과 P 위에서 α만 키우면:
- Target sampling rate: 단조 증가 (0% → 13.3% → 35.6% → 100%)
- Hamming distance: 단조 감소 (27 → 8 → 4 → 0)

100개 인스턴스에서도 **단조성이 완벽하게 유지**된다. posiform signal 강도(α)가 SA의 target 도달을 직접적으로 제어함이 통계적으로 확인된다.

### 2. α=0에서의 축퇴 현상

α=0일 때 Q = Σ R_i (순수 random QUBO). Target은 각 R_i의 최적해이므로 Σ R_i의 ground state이기도 하지만, 축퇴로 인해 SA가 target을 특정하지 못한다 (lin2: 0%, lin20: 1.2%). 그러나 Hamming distance는 27~12로 target **근처**에 있다 — Σ R_i 자체가 target 방향의 signal을 제공하기 때문.

### 3. α=0.001의 축퇴 제거 효과

α=0 → 0.001의 변화만으로도:
- lin2: 0% → 13.3%, Hamming 27 → 8
- lin20: 1.2% → 13.5%, Hamming 12 → 7

극히 작은 posiform signal만으로 축퇴가 깨지고 SA가 target을 찾기 시작한다.

### 4. lin2 vs lin20의 차이

lin20이 lin2보다 전반적으로 SA가 더 잘 푼다:
- α=0.01, sw=5000: lin2 35.6% vs lin20 71.3%

lin20은 계수가 21단계(-1.0 ~ +1.0)로 세분화되어 에너지 landscape가 상대적으로 부드러워, SA가 gradient를 더 잘 따라갈 수 있기 때문으로 해석된다.

## 논문화 가능성 분석

본 실험(Fixed R/P)과 선행 실험(α < 0, ALPHA_NEGATIVE_EXPERIMENT.md)의 결과를 종합하여 논문 소재를 정리한다.

### 소재 1: Planted QUBO 벤치마크의 Signal-Hardness Dilemma

**핵심 주장**: Planted QUBO 벤치마크(Pelofske et al. 2024)에서 target의 유일성을 보장하는 posiform은 동시에 솔버에게 gradient signal을 제공하여 문제를 쉽게 만든다. 유일성과 난이도는 근본적으로 trade-off 관계이다.

**근거 데이터**:
- Fixed R/P 실험: 동일 R, P 위에서 α만 키우면 target rate가 단조 증가 (0% → 13.3% → 35.6% → 100%)
- α < 0 실험: 부호 반전 시 SA가 target 반대 방향으로 이동 (Hamming 28 → 143)
- 에너지 분해: SA가 posiform의 signal을 읽고 따라가는(혹은 반대로 가는) 메커니즘 정량적 확인

**강점**: Pelofske et al. (2024)의 구체적 방법론에 대한 정량적 비판. "벤치마크가 진짜 어려운 문제를 만드는가?"는 양자 컴퓨팅 벤치마킹 커뮤니티에서 중요한 질문. Fixed R/P 실험 설계가 기존에 없던 깔끔한 대조 실험.

**한계**: SA 하나만으로 실험. N=500 한 크기에서만 실험.

### 소재 2: Posiform의 이중 효과 — 축퇴 제거와 Landscape 변형의 분리

**핵심 주장**: Posiform은 두 가지 독립적 효과를 동시에 가진다. (1) 축퇴 제거 (degenerate GS → unique GS), (2) energy landscape 변형 (gradient signal 생성). 이 두 효과는 분리 관찰 가능하다.

**근거 — 비단조적 GS 도달률 (lin2, sw=1000)**:

| α | GS 에너지% | 해석 |
|---|---|---|
| 0 | **82.4%** | 평탄한 landscape → GS 에너지 쉽게 도달 (but 축퇴) |
| 0.001 | **10.4%** | 축퇴 깨짐 + signal 약함 → 가장 어려움 |
| 0.01 | 24.0% | signal 강화로 회복 |
| 0.1 | 99.6% | 강한 signal → 쉬움 |

α=0 → 0.001에서 GS≠Target이 4122 → 0으로 (축퇴 완전 제거), 동시에 GS 도달률 82.4% → 10.4%로 급락 (landscape이 어려워짐). 이 두 현상이 동일한 α 전환에서 동시에 발생한다.

**강점**: 82.4% → 10.4% → 24.0% → 99.6%의 비단조적 패턴은 새로운 관찰. Planted problem에서 "uniqueness를 만드는 비용"을 정량화. Constraint satisfaction 문제의 condensation transition과의 유사성을 논할 수 있음.

**한계**: 이론적 분석(왜 비단조적인지의 수학적 설명) 부재. 임계점 α_c의 정확한 위치 미특정.

### 소재 3: α < 0 대조 실험 — Posiform은 방향성 벡터장이다

**핵심 주장**: Posiform이 "축퇴 제거 장치"인지 "방향성 gradient signal"인지는 α의 부호를 반전하면 결정적으로 판별 가능하다.

**근거**:
- 가설 A (축퇴 제거): α < 0에서 Hamming ≈ α=0 예측 → **기각** (28 vs 143)
- 가설 B (방향성 signal): α < 0에서 Hamming > α=0 예측 → **지지**
- Hamming이 α에 대해 -0.1 ~ +0.1 전 구간에서 단조 감소
- α=-0.1에서도 Hamming < 250 (random guess): Σ R_i와 αP 두 힘의 경쟁으로 설명

**강점**: 가설 검증 구조가 명확 (A vs B). Pelofske et al. (2024) uniqueness 증명에서 α > 0이 암묵적 전제임을 실험으로 확인.

**한계**: α < 0은 실용적 의미가 없으므로 순수 분석적 기여.

### 소재 4 (통합): Planted Problem의 근본적 한계

소재 1~3을 하나의 narrative로 통합:

| 실험 | 증명 |
|---|---|
| α=0 (posiform 제거) | GS 에너지 92.6% 도달, target 0% → 난이도의 실체는 축퇴 |
| α < 0 (posiform 반전) | SA가 target 반대로 이동 → posiform은 방향성 signal |
| Fixed R/P (α 연속 변화) | α와 solvability의 단조적 관계 → signal 강도가 난이도를 직접 제어 |
| 비단조적 GS 도달률 | 유일성 확보와 동시에 landscape 어려워짐 → posiform의 이중 효과 |

> Planted QUBO 벤치마크에서 답을 유일하게 만드는 장치(posiform)는 단순한 축퇴 제거가 아니라 솔버에게 방향성 gradient signal을 제공한다. 이 signal은 α의 부호에 따라 방향이 반전되며, α의 크기에 따라 강도가 조절된다. 이는 planted problem의 근본적 딜레마 — signal 없이 유일성을 보장할 수 없고, signal이 있으면 문제가 쉬워진다 — 의 정량적 증거이다.

### 가장 유력한 논문 구성

**소재 4 (통합 narrative) + 소재 2 (비단조적 패턴)** 조합이 가장 유력.

### 보강이 필요한 부분

1. **N-scaling**: N=100, 200, 1000 등에서 동일 패턴 확인
2. **다른 솔버**: SA 외에 최소 하나 (예: D-Wave SA variant, greedy solver)
3. **이론적 뒷받침**: 비단조적 패턴에 대한 수학적 직관 (random matrix theory 또는 statistical physics 관점)
4. **다른 planted 방법과의 비교**: quiet planting, Wishart에서도 유사한 signal leakage가 있는가
