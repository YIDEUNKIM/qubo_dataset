# Truth Table QUBO 벤치마크 — 구현 계획서

## 1. 핵심 아이디어

모든 $2^n$개 비트스트링에 대해 에너지를 직접 지정하고, 이를 정확히 재현하는 QUBO를 구성한다.

```
입력: {bitstring → energy} 진리표 (2^n 개)
출력: Q 행렬 (QUBO), ground state 보장
```

**예시 (n=3):**
```
000→3, 001→4, 010→4, 011→5, 100→3, 101→5, 110→2, 111→1
→ ground state = 111 (energy=1) ✓
```

## 2. 수학적 기반

### Step 1: Möbius 변환 (진리표 → 다중선형 다항식)

임의의 함수 $f: \{0,1\}^n \to \mathbb{R}$은 **유일한** 다중선형 다항식으로 표현 가능:

$$f(x) = \sum_{S \subseteq [n]} c_S \prod_{i \in S} x_i$$

계수 $c_S$는 포함-배제 원리로 계산:

$$c_S = \sum_{T \subseteq S} (-1)^{|S|-|T|} f(\mathbf{1}_T)$$

여기서 $\mathbf{1}_T$는 $T$에 속하는 위치만 1인 비트스트링.

**사용자 예시 검증:**
```
c_∅ = f(000) = 3              (상수항)
c_{3} = f(001) - f(000) = 1   (x₃)
c_{2} = f(010) - f(000) = 1   (x₂)
c_{1} = f(100) - f(000) = 0   (x₁)
c_{2,3} = f(011)-f(010)-f(001)+f(000) = 0    (x₂x₃)
c_{1,3} = f(101)-f(100)-f(001)+f(000) = 1    (x₁x₃)
c_{1,2} = f(110)-f(100)-f(010)+f(000) = -2   (x₁x₂)
c_{1,2,3} = f(111)-f(110)-f(101)-f(011)+f(100)+f(010)+f(001)-f(000) = -3  (x₁x₂x₃)

→ f(x) = 3 + x₂ + x₃ + x₁x₃ - 2x₁x₂ - 3x₁x₂x₃
```

### Step 2: 항 분류

| 차수 | 처리 방법 | QUBO 배치 |
|------|-----------|-----------|
| 0 (상수) | 에너지 오프셋으로 기록 | 무시 가능 |
| 1 (선형) | $c_i x_i$ → $Q_{ii} += c_i$ | 대각 |
| 2 (이차) | $c_{ij} x_i x_j$ → $Q_{ij} += c_{ij}$ | 비대각 |
| **≥3 (고차)** | **Rosenberg 차수축소 필요** | **보조변수 도입** |

### Step 3: Rosenberg 차수축소

$k$차 단항식 $c \cdot x_{i_1} x_{i_2} \cdots x_{i_k}$에 대해:

1. 보조변수 $y_1 = x_{i_1} x_{i_2}$ 도입
2. 패널티 $M(x_{i_1} x_{i_2} - 2x_{i_1} y_1 - 2x_{i_2} y_1 + 3y_1)$ 추가 → $y_1 = x_{i_1} x_{i_2}$ 강제
3. 원래 항을 $c \cdot y_1 \cdot x_{i_3} \cdots x_{i_k}$로 치환
4. 여전히 차수 > 2이면 반복 (체이닝)

**필요 보조변수**: $k$차 단항식 1개당 $k - 2$개

## 3. 확장성 분석

| n | 진리표 크기 | 최대 고차항 수 | 최대 보조변수 수 | 총 QUBO 크기 | 실용성 |
|---|------------|---------------|-----------------|-------------|--------|
| 3 | 8 | 1 | 1 | 4 | 즉시 |
| 5 | 32 | 16 | 26 | ~31 | 즉시 |
| 8 | 256 | 219 | 502 | ~510 | 가능 |
| 10 | 1,024 | 968 | 3,084 | ~3,094 | 가능 |
| 12 | 4,096 | 4,017 | ~14,000 | ~14,012 | 무거움 |
| 15 | 32,768 | ~32,600 | ~130,000 | ~130,015 | 한계 |
| 20 | 1,048,576 | — | — | — | 비실용적 |

**핵심 병목**: 보조변수 수가 진리표 크기에 비례하여 폭발. 실용적 한계는 **n ≤ 12~15**.

단, 에너지 함수가 구조를 가지면 (예: 저차항 위주) 고차 계수가 0이 되어 보조변수를 크게 줄일 수 있음.

## 4. 구현 계획

### 파일: `truthtable/qubo_truthtable.py`

```
모듈 구성:
├── mobius_transform(truth_table)       # 진리표 → 다중선형 계수
├── classify_terms(coefficients)        # 계수를 차수별 분류
├── rosenberg_reduce(high_order_terms)  # 고차항 → 2차 + 보조변수 + 패널티
├── assemble_qubo(linear, quadratic, reduced, penalty_strength)  # Q 행렬 조립
├── compute_penalty_strength(coefficients)  # 최소 M 자동 계산
├── verify_qubo(Q, truth_table, n_original)  # 전수검사 검증
└── create_qubo_truthtable(truth_table, seed)  # 메인 진입점
```

### 구현 순서

| 단계 | 내용 | 세부 사항 |
|------|------|-----------|
| **1** | `mobius_transform()` | Möbius 변환 구현 (O(n·2ⁿ) fast zeta/Möbius 알고리즘) |
| **2** | `classify_terms()` | 상수/선형/이차/고차 분류 + 0이 아닌 항만 필터 |
| **3** | `rosenberg_reduce()` | 체이닝 방식 차수축소, 보조변수 인덱스 관리 |
| **4** | `compute_penalty_strength()` | M > max energy range 보장하는 최소 M 계산 |
| **5** | `assemble_qubo()` | 원래 2차 이하 항 + 축소된 항 + 패널티 → Q dict |
| **6** | `verify_qubo()` | 모든 2ⁿ 비트스트링 전수검사 (원래 변수만 고려, 보조변수는 최적값으로) |
| **7** | 메인 + CLI | `create_qubo_truthtable()`, CLI 인터페이스, `qubo_utils` 연동 |
| **8** | 테스트 | SA 실험 (`test_truthtable.py`), 기존 방법론과 비교 |

### 패널티 강도 M 결정 전략

```
M 하한 = max(truth_table) - min(truth_table) + 1
```
이렇게 하면 보조변수 위반 시 에너지가 반드시 진리표 최대값을 초과 → ground state 보장.

더 정밀하게는 각 축소 단계별로 해당 고차항의 최대 기여 에너지를 계산하여 개별 M 설정 가능.

### 입력 형식

```python
# 방법 1: 딕셔너리
truth_table = {"000": 3, "001": 4, "011": 5, "111": 1, "101": 5, "010": 4, "100": 3, "110": 2}

# 방법 2: 리스트 (비트스트링 사전순)
truth_table = [3, 4, 4, 5, 3, 5, 2, 1]  # 000, 001, 010, 011, 100, 101, 110, 111

# 방법 3: 에너지 함수 (큰 n에서 구조화된 입력)
def energy_fn(x: str) -> float:
    return hamming_distance(x, target) ** 2 + noise
```

### 출력

- Q 행렬 (dict 형식, 기존 프로젝트와 동일)
- `results/` 디렉토리에 edge-list CSV 저장
- 메타데이터: 원래 n, 보조변수 수, 총 QUBO 크기, ground state, 패널티 M

## 5. 벤치마크 활용 방안

| 활용 | 설명 |
|------|------|
| **에너지 랜드스케이프 제어** | local minima 수, energy gap 등을 직접 설계 가능 |
| **난이도 조절** | 에너지 분포를 조절하여 SA-easy ~ SA-hard 스펙트럼 생성 |
| **솔버 정밀 평가** | ground state뿐 아니라 전체 에너지 순위를 알고 있으므로 솔버의 "근사 품질" 평가 가능 |
| **기존 방법론과 비교** | 7-way comparison에 추가 (TruthTable vs McEliece vs Hardened vs ...) |

## 6. 에너지 함수 프리셋 (제안)

완전 랜덤 진리표 외에, 구조화된 프리셋을 제공하여 흥미로운 벤치마크 생성:

```python
# 프리셋 1: Hamming 거리 기반 (저차항 위주 → 보조변수 적음)
E(x) = hamming(x, target)^2

# 프리셋 2: 다중 계곡 (여러 local minima)
E(x) = min(hamming(x, v1), hamming(x, v2), ...) + noise

# 프리셋 3: 랜덤 (최대 난이도, 보조변수 최대)
E(x) ~ Uniform(0, 100)

# 프리셋 4: 에너지 갭 제어
E(target) = 0, E(x) = gap + random_positive  (gap으로 난이도 조절)
```

## 7. 한계 및 향후 확장

| 한계 | 대응 방안 |
|------|-----------|
| n ≤ 12~15 실용적 한계 | 구조화된 에너지 함수 사용 시 고차항 감소 → 더 큰 n 가능 |
| 보조변수 폭발 | 스파스 진리표 (일부 비트스트링만 에너지 지정) 모드 추가 고려 |
| 패널티 M이 크면 수치 불안정 | 계층적 M 결정 (항별 개별 M) |
| QUBO 구조가 인위적 | 랜덤 에너지 + Gaussian 노이즈로 자연스러운 문제 생성 |
