# Hardened Posiform α < 0 실험 결과

## 실험 목적

α=0 실험의 후속 실험. Posiform이 "축퇴 제거 장치"인지 "방향성 gradient signal"인지를 결정적으로 판별한다.

**핵심 질문**: α의 부호를 뒤집으면 posiform은 target **반대 방향**으로 작용하는가?

### 왜 이 실험이 필요한가

α=0 실험만으로는 posiform의 역할에 대해 두 가지 해석이 가능하다:

| 해석 | 설명 | α=0 결과와의 호환성 |
|---|---|---|
| (A) 축퇴 제거 장치 | degenerate GS 중 하나를 선택해줄 뿐 | O — 제거하면 축퇴 발생 |
| (B) 방향성 signal | SA를 target 쪽으로 적극적으로 끌어당김 | O — 제거하면 signal 소실 |

α=0 결과는 (A)와 (B) 모두와 호환된다. α < 0 실험이 이 모호성을 제거한다:
- (A)가 맞다면: α < 0에서 Hamming은 α=0과 비슷해야 함 (축퇴 제거 장치에는 "방향"이 없으므로)
- (B)가 맞다면: α < 0에서 Hamming은 α=0보다 **커야** 함 (signal이 반대로 작용하므로)

## 배경

```
Q_final = Σ R_i + α × P
```

| α 범위 | target이 GS? | target이 local min? | posiform의 역할 |
|---|---|---|---|
| α > 0 | O (유일) | O (min_flip_delta > 0) | target으로 끌어당김 |
| α = 0 | O (축퇴) | O (min_flip_delta = 0) | 없음 |
| α < 0 | **X** | **X** (min_flip_delta < 0) | target에서 밀어냄 |

### 논문 증명과의 관계

Pelofske et al. (2024) Section 2.2의 uniqueness 증명:

```
Q(X*) = Σ R_i(X*) + αP(X*) < Σ R_i(X̂) + αP(X̂) = Q(X̂)
```

이 증명은 P(X\*) < P(X̂)에 α를 곱할 때 부등호 방향이 유지되어야 하므로, **α > 0을 암묵적으로 전제**한다. α < 0이면 αP(X\*) > αP(X̂)가 되어 부등호가 보장되지 않는다. 본 실험은 이 수학적 관찰을 실험적으로 검증한다.

### 주의: Hamming distance는 SA 성능 지표가 아니다

α < 0에서 target은 ground state가 아니므로, SA가 target에서 멀어지는 것은 **SA가 정상 작동한 결과**이지 실패가 아니다. 여기서 Hamming distance는 SA의 성능을 평가하는 지표가 아니라, **posiform의 성질을 측정하는 진단 도구**로 사용된다.

이 실험의 핵심 논리: α를 바꿔가며 SA 해가 target 기준으로 어디에 있는지를 관찰함으로써, posiform이 축퇴 제거 장치인지 방향성 signal인지를 판별한다.

| posiform의 정체 | α < 0일 때 예측 | 실제 결과 |
|---|---|---|
| 축퇴 제거 장치 | Hamming ≈ α=0과 비슷 | ❌ |
| 방향성 gradient signal | Hamming > α=0 (반대 방향) | ✅ (28 → 143) |

α < 0이라는 "의도적으로 잘못된 설정"에서 target까지의 거리를 재는 것 자체가 이 대조 실험의 핵심이다.

### Hamming vs Random Guess 비교

N=500에서 random guess의 기대 Hamming = 250.

| α | lin2 Hamming med | lin20 Hamming med | 해석 |
|---|---|---|---|
| -0.1 | 143 (< 250) | 180 (< 250) | Σ R_i의 signal과 αP의 anti-signal이 경쟁 |
| 0 | 28 | 10 | Σ R_i의 signal만 작용 |
| +0.1 | 0 | 0 | Σ R_i + αP가 같은 방향으로 협력 |

α=-0.1에서도 Hamming이 250보다 작은 이유: Σ R_i는 여전히 target 방향으로 끌어당기고 있다 (target은 각 R_i의 최적해이므로). αP의 anti-signal이 이를 상쇄하지만 완전히 이기지는 못한다.

Target이 ground state가 아님이 정량적으로 확인된다.

**에너지 분해의 메커니즘:**

α=-0.1에서 SA가 찾은 해를 분해하면:
- R gap = +28.2: Σ R_i 기준으로 target보다 **나쁨** (random QUBO 최적에서 벗어남)
- P gap = +809: posiform P 기준으로 target에서 **훨씬 멀어짐**
- 그러나 αP gap = -0.1 × 809 = **-80.9**: α가 음수이므로 P에서 멀어지는 것이 에너지를 **낮춤**

SA는 "R 기준 약간 손해를 보더라도, P 기준으로 target에서 멀어지는 것이 전체 에너지를 낮추는" 해를 찾고 있다. 이는 SA가 posiform의 signal을 **읽고 반대로 따라가는** 것이다.

**α > 0에서 GS 에너지 일치 = Target 일치 (완벽한 대응):**

α=0.01: 19.8% = 19.8%, α=0.1: 100% = 100%. GS를 찾으면 그것이 곧 target.
α=0에서만 GS 에너지 76.8% vs target 0% (축퇴로 인한 불일치).

## 해석

### 1. Posiform은 "축퇴 제거 장치"가 아닌 "방향성 gradient signal"이다

| 증거 | 설명 |
|---|---|
| α > 0 → Hamming 감소 | signal이 target으로 끌어당김 |
| α = 0 → Hamming 중간 | signal 없음, Σ R_i만 작용 |
| α < 0 → Hamming 증가 | **anti-signal이 target에서 밀어냄** |
| Hamming이 α에 대해 단조 감소 | posiform의 방향성이 연속적 |

"축퇴 제거 장치"라면 α의 부호에 따라 방향이 바뀌지 않는다. 방향 반전은 **방향성 signal만이 가능한 행동**이다.

### 2. 두 힘의 경쟁: Σ R_i vs αP

```
Q = Σ R_i + αP
      ↑         ↑
  target 방향    α>0: target 방향 (협력)
  (항상)         α<0: 반-target 방향 (경쟁)
```

- α > 0: 두 힘이 협력 → SA가 쉽게 target 도달
- α = 0: Σ R_i만 작용 → target 근처의 degenerate GS 중 하나에 도달
- α < 0: 두 힘이 경쟁 → SA가 절충점에 도달 (target도 아니고 complement도 아닌 위치)

### 3. α=0 실험 해석의 강화

α=0 실험에서 "posiform이 gradient signal을 제공한다"는 주장은 간접적 증거에 기반했다 (posiform을 제거하면 SA가 실패한다). α < 0 실험은 **직접적 증거**를 제공한다:
- 부호를 바꾸면 반대 방향으로 작용한다
- 이는 정의상 "방향성 signal"이다

### 4. Pelofske et al. (2024) 논문에 대한 추가 함의

논문의 uniqueness 증명 (Section 2.2)은 α > 0을 명시하지 않지만 암묵적으로 전제한다. 본 실험은 α < 0에서 target이 local minimum조차 아님을 보여주며, 이 암묵적 전제의 필요성을 실험적으로 확인한다.

또한, 논문이 "α를 줄이면 난이도가 증가한다"고 주장할 때, 그 메커니즘은 "random QUBO의 landscape가 어렵기 때문"이 아니라 "posiform signal이 약해지기 때문"임이 α < 0 실험으로 더욱 명확해진다. α를 0 아래로 내리면 signal이 약해지는 것을 넘어 **반대로 작용**하기 시작한다.

### 핵심 관찰: 축퇴 제거의 임계점

**α=0.001에서 이미 "GS 에너지 일치 = Target 일치"가 완벽하게 성립한다.** GS를 찾았는데 target이 아닌 경우가 0개. α=0.001이라는 극히 작은 posiform만으로도 축퇴가 완전히 깨진다.

동시에 주목할 점: **GS 에너지 도달률 자체가 급락한다.**

| α | GS 에너지 도달률 (lin2) | 해석 |
|---|---|---|
| 0 | **80.2%** | landscape 평탄 → 어디서든 GS 에너지에 도달 (but 축퇴) |
| 0.001 | **8.6%** | posiform이 plateau를 깨서 유일한 골짜기를 만듦 → 찾기 어려움 |
| 0.01 | 18.8% | signal 강화로 gradient가 생겨 오히려 회복 |
| 0.1 | 99.4% | 강한 signal로 쉽게 도달 |

이것은 **posiform의 이중 효과**를 보여준다:
1. **축퇴 제거**: α=0 → 0.001에서 plateau가 사라지면서 유일한 GS 생성
2. **Landscape 변형**: 동시에 평탄했던 에너지 landscape에 골짜기와 장벽이 생성

α가 아주 작을 때 (0.001) 축퇴는 깨졌지만 signal이 너무 약해서 SA가 유일한 골짜기를 찾기 어려움. α를 키우면 gradient signal이 강해져서 다시 쉬워진다. 이 **비단조적** 패턴 (80% → 9% → 19% → 99%)이 posiform의 이중 역할을 극적으로 보여준다.

## α=0 실험과의 통합 메시지

| 실험 | 증명하는 것 |
|---|---|
| α=0 | posiform 제거 시 SA가 GS 에너지는 찾지만 target은 못 찾음 → "난이도"의 실체는 축퇴 |
| α<0 | posiform 반전 시 SA가 target에서 적극적으로 멀어짐 → posiform은 방향성 signal |

두 실험을 결합하면:

> Planted QUBO 벤치마크에서 답을 유일하게 만드는 장치(posiform)는 **단순한 축퇴 제거가 아니라 솔버에게 방향성 gradient signal을 제공**한다. 이 signal은 α의 부호에 따라 방향이 반전되며, α의 크기에 따라 강도가 조절된다. 이는 planted problem의 근본적 딜레마 — signal 없이 유일성을 보장할 수 없고, signal이 있으면 문제가 쉬워진다 — 의 정량적 증거이다.
